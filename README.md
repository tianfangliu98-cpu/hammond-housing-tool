# Hammond's Housing Tool / 哈德蒙房屋装修工具

FF14 国服房屋装修辅助，当前适配国服版本。国际服和韩服由于无账号，无法测试是否可用。

由于部分大大的没时间更新工具，自己想装修又得用无汉化的插件，因此借助 DSH 做了一个小工具。第一次做这种工具，有问题留言，我改。

![界面](docs/screenshot.png)

## 功能

- **坐标微调**：X 东西、Y 高度、Z 南北，步长可调，`+` / `−` 支持长按连发
- **旋转调整**：只改朝向，保留家具原有的俯仰和倾斜
- **自动应用**：改完数字立刻写进游戏
- **解除家具限制**：可以摆到墙里、摆到房间外
- **鼠标穿透**：标题栏以下整块穿透，点击直接落到游戏（开关在标题栏）
- **折叠**：标题栏 ▲ 收起整个面板，只剩标题
- **置顶**：金色 = 已开启，灰色 = 已关闭
- **透明度**：40% ~ 100%
- **自检报告**：出问题时一键生成诊断

## 使用说明

1. 下载 [最新 release](https://github.com/tianfangliu98-cpu/hammond-housing-tool/releases/latest) 里的 zip（**推荐 standalone 版，自带运行时，解压即用**），解压到任意空文件夹，并将解压目录加入安全软件的白名单
2. 双击「哈德蒙房屋装修工具.exe」运行。先后启动游戏不影响程序正常使用，程序会自动识别游戏进程
3. 游戏里进入房屋，家具编辑切到**「旋转」模式**
4. **点击**家具选中它（不是鼠标悬停）
5. 此时程序里会显示它的坐标，直接改数字或者点 `+` / `−`
6. 改完在游戏里**点一下空白处**保存位置

### 判断依据

窗口底部的 `模式` / `状态`：

| 显示 | 含义 |
|---|---|
| 模式：Rotate + 状态：Active | 可以改 |
| 状态：Hover | 只是悬停，请点击家具 |
| 未进入布置界面 | 先打开家具编辑 |

## 已知限制
